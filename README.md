# InvoiceMatch AI

**Live Demo:** [https://final-invoice-psi.vercel.app/](https://final-invoice-psi.vercel.app/)

**InvoiceMatch AI** is a premium, modern, production-quality web application designed for micro-enterprises and small businesses in India to simplify GSTR-2B invoice reconciliation.

## Features
- **AI-Powered Matching**: Understands small differences in supplier names, invoice numbers, and formatting automatically.
- **GST-Aware**: Designed specifically around Indian GST invoice data, HSN codes, and standard tax rates.
- **Match Confidence**: Every matched record receives a clear percentage confidence score based on similarity.
- **Smart Review & Corrections**: Identifies likely data entry errors and formatting inconsistencies with one-click fixes.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Getting Started

1. Clone the repository
2. Install dependencies with `npm install`
3. Run the development server with `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
